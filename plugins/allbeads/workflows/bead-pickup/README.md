# bead-pickup

Turns "what should I work on?" into a procedure with a record.

`bd ready` answers the question in one command, but the answer is the easy
part. The work is choosing between the issues, reading what earlier sessions
already settled in the comments, and arriving at a first change that is
concrete enough to start. That is three turns of judgment, and doing it the
same way twice is what makes the runs comparable.

Each run lands under `runs/` with its checks decided, so a session that picked
badly is visible later as a run whose plan step went nowhere.

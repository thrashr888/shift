Shift documentation

Shift is a coding agent that runs in your terminal. Its behavior is a Scheme file you edit while it runs, every turn ends with a receipt, and its workflows improve under measurement. These pages explain how to install it, run it, change it, and check it.

The repository's own documentation stays the reference for every setting; these pages are the guided path through it.

Start

  • Install and first session: Homebrew or a checkout, the demo model, your first turn.
  • Providers and keys: Ollama, Claude, OpenAI-compatible endpoints, context limits.
  • The terminal: the sidebar, themes, panes, and the commands that persist.

Use

  • Modes and policy: manual, plan, autopilot, the run allowlist, the judge.
  • Receipts and sessions: what a receipt lists, sessions as folders, recall across them.
  • Workflows: define, run and improve a procedure with checks.
  • Subagents: children as sessions under the parent, run as jobs.

Change

  • The agent file: /eval, generations and /rollback.
  • Pane packs: a project's own inspector tab as data.
  • Attach a desktop agent: the session's MCP endpoint for Codex, Claude Desktop and others.

Measure

  • Evals: the benchmark runs, with their dates and caveats.
  • The judge: the typed judge, its confidence, and how it is measured.
